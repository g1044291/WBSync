# UI設計書

## 1. 技術スタック

| 項目 | 採用技術 |
|------|----------|
| フレームワーク | Electron |
| UIライブラリ | React + TypeScript |
| テーマ | ライトモードのみ |

***

## 2. 画面一覧

| 画面ID | 画面名 | 概要 |
|--------|--------|------|
| S01 | プロジェクト一覧 | アプリ起動時の初期画面。プロジェクトを選択してWBSへ遷移 |
| S02 | ガントチャート | プロジェクトのWBSをタスクツリー＋ガントチャートで表示・編集 |
| S03 | タスク編集モーダル | タスクの新規作成・編集を行うポップアップ |
| S04 | 休日設定 | アプリ全体の休日（祝日等）を登録・管理 |
| S05 | 担当者一覧 | プロジェクトに登録された担当者の一覧 |
| S06 | 担当者詳細 | 担当者名と個人休日を設定 |
| S07 | プロジェクト作成モーダル | プロジェクトの新規作成を行うポップアップ |

***

## 3. 画面遷移

```
[起動]
  └─► S01 プロジェクト一覧
        ├─ プロジェクトをクリック ──────────────► S02 ガントチャート
        │                                              ├─ タスク行クリック ──► S03 タスク編集モーダル（編集）
        │                                              ├─ 右クリックメニュー「追加」─► S03 タスク編集モーダル（新規）
        │                                              ├─ 担当者設定ボタン ──► S05 担当者一覧
        │                                              │                          └─ 担当者クリック ─► S06 担当者詳細
        │                                              └─ 戻るボタン ────────► S01 プロジェクト一覧
        ├─ 新規登録ボタン ────────────────────► S07 プロジェクト作成モーダル
        └─ 休日設定ボタン ────────────────────► S04 休日設定
```

### S02 ガントチャート

#### レイアウト

```
┌──────────────────────────────────────────────────────────────────────┐
│ [←戻る]  プロジェクトA          [担当者設定]   [日 | 週 | 月]        │  ← ヘッダー
├────────────────────────────────┬─────────────────────────────────────┤
│ タスク名    担当 工数 開始  終了 ス 進 │ 6/1  6/2  6/3  6/4  6/5  6/6 ...  │
│            当者      日   日 タ 捗 │                                     │
├────────────────────────────────┼─────────────────────────────────────┤
│ ▼ フェーズ1      - 10  6/1  6/14 未  0% │ ████████████████████            │
│   ▶ タスクA    山田  5  6/1  6/7  進 60% │ ██████████                      │
│   ▶ タスクB    鈴木  3  6/8  6/11 未  0% │          ██████                 │
│ ▼ フェーズ2      -  8  6/12 6/21 未  0% │                   ████████████  │
│   ▶ タスクC    山田  4  6/12 6/17 未  0% │                   ████████      │
├────────────────────────────────┼─────────────────────────────────────┤
│ [+ タスクを追加]                │                                     │
└────────────────────────────────┴─────────────────────────────────────┘
```

#### 要素

| 要素 | 説明 |
|------|------|
| 戻るボタン | S01（プロジェクト一覧）へ戻る |
| プロジェクト名 | 現在のプロジェクト名を表示 |
| 担当者設定ボタン | S05（担当者一覧）へ遷移 |
| スケールスイッチャー | 日 / 週 / 月 を切り替えるタブ or ボタン |
| タスク行 | クリックでS03（タスク編集モーダル）を開く |
| 階層展開アイコン | ▼/▶ で子タスクの表示/非表示を切り替え |
| 右クリックメニュー | 後述 |
| タスクを追加ボタン | ルートレベルのタスクを追加。クリックでS03（新規）を開く |
| ガントバー | タスクの期間をバーで表示（ドラッグ操作なし） |

#### タスクリスト列

| 列名 | 幅 | 備考 |
|------|----|------|
| タスク名 | 広め | 階層に応じてインデント。折りたたみアイコン付き |
| 担当者 | 固定 | 親タスクは「-」表示 |
| 工数 | 固定 | 単位：人日。親タスクは「-」表示 |
| 開始日 | 固定 | |
| 終了日 | 固定 | |
| ステータス | 固定 | バッジ or ラベル表示 |
| 進捗率 | 固定 | 数値（%）表示 |

#### 右クリックメニュー

```
┌──────────────────────────┐
│ 子タスクを追加            │
│ 同階層にタスクを追加      │
│ ──────────────────────── │
│ タスクを削除              │
└──────────────────────────┘
```

| 項目 | 動作 |
|------|------|
| 子タスクを追加 | S03（新規）を開く。作成したタスクは右クリックしたタスクの最後の子として追加 |
| 同階層にタスクを追加 | S03（新規）を開く。作成したタスクは同じ親の最後の子として追加 |
| タスクを削除 | 確認ダイアログを表示後、タスクとその配下を削除。依存参照は削除 |

#### タスクの並び替え

* 同一階層内でドラッグ＆ドロップによる順序変更が可能
* 異なる階層への移動は不可

#### ガントチャートのスケール

| スケール | 列単位 | 表示例 |
|----------|--------|--------|
| 日 | 1列 = 1日 | 6/1, 6/2, 6/3 … |
| 週 | 1列 = 1週間 | 6/1〜6/7, 6/8〜6/14 … |
| 月 | 1列 = 1ヶ月 | 6月, 7月, 8月 … |

#### 依存関係の警告表示

* 前タスクの終了日より前に開始日が設定されているタスクの行を視覚的に警告表示（警告アイコンなど）

### S03 タスク編集モーダル

#### レイアウト

```
┌────────────────────────────────────────┐
│ タスクを編集                        [×] │
├────────────────────────────────────────┤
│ タスク名  [________________________]   │
│ 担当者    [担当者を選択 ▼]             │
│ 工数      [___] 人日                   │
│ 開始日    [____/____/____]             │
│ 終了日    [____/____/____]             │
│ 依存タスク [タスクを選択 ▼]            │
│ ステータス [未着手 ▼]                  │
│ 進捗率    [___] %                      │
│ 備考      [________________________]   │
│           [________________________]   │
│                                        │
│              [キャンセル]  [保存]      │
└────────────────────────────────────────┘
```

#### 要素

| 項目 | 入力形式 | 備考 |
|------|----------|------|
| タスク名 | テキスト入力 | 必須 |
| 担当者 | ドロップダウン | プロジェクト内の担当者一覧から選択 |
| 工数 | 数値入力 | 人日単位 |
| 開始日 | 日付ピッカー | 変更時に終了日を自動再計算（工数ベース） |
| 終了日 | 日付ピッカー | 手動変更可。工数との一致は不要 |
| 依存タスク | ドロップダウン | プロジェクト内タスクから選択（自分自身・子孫は除外）。空欄も可 |
| ステータス | ドロップダウン | 未着手 / 進行中 / 完了 / 保留 |
| 進捗率 | 数値入力 | 0〜100 |
| 備考 | テキストエリア | 任意 |

## 5. 共通ルール

### ステータスの表示

| ステータス | バッジカラー |
|------------|-------------|
| 未着手 | グレー |
| 進行中 | ブルー |
| 完了 | グリーン |
| 保留 | オレンジ |

### モーダルの共通動作

* 背景クリック or [×] ボタンで閉じる（未保存の変更がある場合は確認ダイアログを表示）
* [キャンセル] ボタンで変更を破棄して閉じる
* [保存] / [作成] ボタンでバリデーション後に保存

### 削除確認ダイアログ

タスク削除時は以下のダイアログを表示：

```
┌────────────────────────────────────┐
│ タスクを削除しますか？              │
│                                    │
│ 「タスクA」およびその配下のタスクを │
│ すべて削除します。この操作は元に    │
│ 戻せません。                        │
│                                    │
│              [キャンセル]  [削除]  │
└────────────────────────────────────┘
```
