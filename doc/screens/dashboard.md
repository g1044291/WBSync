# ダッシュボード

## レイアウト

```
┌──────────────────────────────────────────────────────────────────────┐
│ [←戻る]  プロジェクトA - ダッシュボード                              │  ← ヘッダー
├──────────────────────────────────────────────────────────────────────┤
│ 集計期間  [    /  /  ] 〜 [    /  /  ]   未指定の場合は全期間を集計します│  ← ツールバー
├──────────────────────────────────────────────────────────────────────┤
│ 担当者          予定工数   実績    遅れ                              │
├──────────────────────────────────────────────────────────────────────┤
│ ▽山田           10.0人日   8.5人日  +1.5人日（前倒し）               │
│     フェーズ1                                                        │
│       タスクA                        5.0人日  3.0人日  +2.0人日（前倒し）│
│       タスクB [実績のみ]                       1.0人日  -            │
│ ▷鈴木            6.0人日   7.0人日  -1.0人日（遅れ）                  │
│ ▷佐藤            0.0人日   0.0人日  0人日                            │
├──────────────────────────────────────────────────────────────────────┤
│ 合計            16.0人日  15.5人日  +0.5人日（前倒し）                │
└──────────────────────────────────────────────────────────────────────┘
```

## 要素

| 要素 | 説明 |
|------|------|
| 戻るボタン | [ガントチャート](gantt-chart.md) へ戻る |
| 集計期間ツールバー | 開始日・終了日を指定する日付入力（両方任意）。指定すると集計モードが切り替わる（[集計期間の指定](#集計期間の指定)） |
| 担当者一覧 | プロジェクトに登録された全担当者を、担当者名の五十音順で表示（実績・担当タスクの有無は問わない） |
| 展開アイコン | 担当者行の左端。クリックで当該担当者のタスクツリーを展開/折りたたみ |
| 合計行 | 一覧末尾に表示する、全担当者の予定工数・実績・遅れの合算行。展開はできない |

## 集計期間の指定

集計期間（開始日・終了日）を指定すると、指定期間内に記録された実績のみを集計できる。詳細は[担当者別集計: 集計期間の指定](../requirements/effort-management.md#集計期間の指定)を参照。

| 状態 | 表示内容 |
|------|---------|
| **未指定（デフォルト）** | 従来どおり。予定工数・実績・遅れの3列を表示する（実績は全期間の `work_logs` を集計） |
| **期間指定あり** | 予定工数・遅れの列を**表示しない**（期間内実績のみの集計であり、予定との比較を行わないため）。実績列のみを表示し、その値は指定期間内に記録された `work_logs` のみの合計。担当者行を展開したタスクツリーも同様に実績列のみ |

* 開始日・終了日はいずれか一方のみの指定も可（片側は無制限）。両端の日を含む
* 期間指定時は「（期間）に記録された実績のみを集計しています（予定工数・遅れは表示しません）」というヘッダー表示を出す
* 「全期間に戻す」ボタンで指定を解除し、未指定状態に戻す

## 集計列（担当者行）

| 列名 | 内容 |
|------|------|
| 予定工数 | **現在**この担当者が割り当てられているタスクの予定工数合計（人日）。算出方法は[担当者別集計](../requirements/effort-management.md#担当者別集計ダッシュボード)を参照 |
| 実績 | この担当者自身が**記録した**実績の合計（人日、`work_logs.minutes` 合計 ÷ 480）。タスクの現在の担当者は問わない |
| 遅れ | 予定工数合計 − 実績合計。プラスは前倒し（緑）、マイナスは遅れ（赤）で表示 |

数値には単位「人日」を付与して表示する（例：`10.0人日`、`+1.5人日（前倒し）`）。算出不可（`-`）の場合は単位を付けない。

予定工数と実績は集計基準が異なる（予定工数＝現在の担当者、実績＝実績記録時点の担当者）ため、あるタスクの現在の担当者と実績記録者が異なる場合、両者がそれぞれ一覧に表示されうる。詳細は[担当者別集計](../requirements/effort-management.md#担当者別集計ダッシュボード)を参照。対象タスク・実績のいずれもない担当者は予定工数0・実績0・遅れ0で表示する。

## タスクツリー（行展開）

担当者行を展開すると、その担当者が関わったタスクの一覧を階層構造（ツリー）で表示する。詳細な対象条件・算出方法は[担当者別タスク一覧](../requirements/effort-management.md#担当者別タスク一覧ダッシュボード行展開)を参照。

| 列名 | 内容 |
|------|------|
| タスク名 | 階層に応じてインデント表示。子タスクを持つ行は集計値を表示しない（すべて「-」） |
| [実績のみ]バッジ | 現在このタスクの担当者ではないが、実績を記録したことがあるタスクの行に表示 |
| 予定工数 | 現在の担当タスクのみ表示。[実績のみ]の行は「-」 |
| 実績 | 現在の担当タスクはタスクの実績合計、[実績のみ]の行はこの担当者が記録した分のみ |
| 遅れ | 現在の担当タスクのみ算出。[実績のみ]の行は「-」 |

## 空データ時の表示

プロジェクトに担当者が1人も登録されていない場合、「担当者が登録されていません」と表示する（合計行も表示しない）。
