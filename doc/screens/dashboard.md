# ダッシュボード

## レイアウト

```
┌──────────────────────────────────────────────────────────────────────┐
│ [←戻る]  プロジェクトA - ダッシュボード                              │  ← ヘッダー
├──────────────────────────────────────────────────────────────────────┤
│ 担当者          予定工数   実績    遅れ                              │
├──────────────────────────────────────────────────────────────────────┤
│ ▽山田           10.0       8.5     +1.5（前倒し）                    │
│     フェーズ1                                                        │
│       タスクA                        5.0     3.0    +2.0（前倒し）   │
│       タスクB [実績のみ]                       1.0     -             │
│ ▷鈴木            6.0       7.0     -1.0（遅れ）                      │
└──────────────────────────────────────────────────────────────────────┘
```

## 要素

| 要素 | 説明 |
|------|------|
| 戻るボタン | [ガントチャート](gantt-chart.md) へ戻る |
| 担当者一覧 | 集計対象タスクを1件以上持つ担当者のみ、担当者名の五十音順で表示 |
| 展開アイコン | 担当者行の左端。クリックで当該担当者のタスクツリーを展開/折りたたみ |

## 集計列（担当者行）

| 列名 | 内容 |
|------|------|
| 予定工数 | 担当者ごとの予定工数合計（人日）。算出方法は[担当者別集計](../requirements/effort-management.md#担当者別集計ダッシュボード)を参照 |
| 実績 | 担当者ごとの実績合計（人日、`work_logs.minutes` 合計 ÷ 480） |
| 遅れ | 予定工数合計 − 実績合計。プラスは前倒し（緑）、マイナスは遅れ（赤）で表示 |

集計対象タスクの条件（担当者設定あり／実績が1件以上。ステータスは問わない）は[担当者別集計](../requirements/effort-management.md#担当者別集計ダッシュボード)を参照。

## タスクツリー（行展開）

担当者行を展開すると、その担当者が関わったタスクの一覧を階層構造（ツリー）で表示する。詳細な対象条件・算出方法は[担当者別タスク一覧](../requirements/effort-management.md#担当者別タスク一覧ダッシュボード行展開)を参照。

| 列名 | 内容 |
|------|------|
| タスク名 | 階層に応じてインデント表示。子タスクを持つ行は集計値を表示しない（すべて「-」） |
| [実績のみ]バッジ | 現在このタスクの担当者ではないが、実績を記録したことがあるタスクの行に表示 |
| 予定工数 | 現在の担当タスクのみ表示。[実績のみ]の行は「-」 |
| 実績 | 現在の担当タスクはタスクの実績合計、[実績のみ]の行はこの担当者が記録した分のみ |
| 遅れ | 現在の担当タスクのみ算出。[実績のみ]の行は「-」 |

## 空データ時の表示

集計対象タスクを持つ担当者が1人もいない場合、「集計対象のタスクがありません」と表示する。
