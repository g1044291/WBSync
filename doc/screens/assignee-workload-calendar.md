# 担当者別稼働時間カレンダー

## レイアウト

```
┌──────────────────────────────────────────────────────────────────────┐
│ [←戻る]  プロジェクトA - 稼働時間カレンダー （各セルは実績時間の合計・分） │  ← ヘッダー
├──────────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬───────────┤
│ 担当者   │ 6/1  │ 6/2  │ 6/3  │ 6/4  │ 6/5  │ 6/6  │ 6/7  │ ...       │
├──────────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┼───────────┤
│ 山田     │ 480  │ 480  │      │ 240  │ 480  │      │      │ ...       │
│ 鈴木     │      │ 360  │ 480  │ 480  │      │      │      │ ...       │
└──────────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┴───────────┘
```

## 要素

| 要素 | 説明 |
|------|------|
| 戻るボタン | [ガントチャート](gantt-chart.md) へ戻る |
| 担当者列 | プロジェクトに登録された全担当者を [担当者一覧](assignee-list.md) と同じ表示順（`sort_order`）で表示。実績の有無に関わらず全員を表示する（入力漏れの把握が目的のため、[ダッシュボード](dashboard.md)のような「実績1件以上」の絞り込みは行わない） |
| 日付列 | 日単位（ガントチャートと同様に日付を横軸に並べる）。表示範囲は後述 |
| セル | 当該担当者・当該日の `work_logs.minutes` 合計を分単位の数値で表示。実績が0の場合は空欄 |

## 表示範囲

* 開始日: プロジェクト開始日。ただし、その日より前に記録された実績ログがある場合はその最古の日付まで広げる
* 終了日: 全タスクの終了日の最大値＋30日。ただし、それより後に記録された実績ログがある場合はその最新の日付まで広げる
* 表示範囲外に実績が取りこぼされることがないよう、記録済み実績の日付は必ず範囲に含める

## 強調表示

* 数値を敷き詰めて表示するため、罫線は[ガントチャート](gantt-chart.md)より濃い目の色にし、セルの区切りを見やすくする
* 稼働日/休日による色分けなどの強調表示は行わない（数値表示のみ）

## スクロール

* 担当者列（左端）とヘッダー行（上端）を固定（sticky）し、日付列を横スクロールしても担当者名・日付が常に見える

## 空データ時の表示

* プロジェクトに担当者が1人も登録されていない場合、「担当者が登録されていません」と表示する
