# タスク編集モーダル

## レイアウト

```
┌────────────────────────────────────────┐
│ タスクを編集                        [×] │
├────────────────────────────────────────┤
│ タスク名  [________________________]   │
│ 親タスク  [タスクを選択 ▼]             │
│ 担当者    [担当者を選択 ▼]             │
│ 工数      [___] 人日  進捗率 [___] %   │
│ 開始日    [____/____/____]             │
│ 終了日    [____/____/____]             │
│ [終了日を計算] [先行タスクから開始日を設定]│
│ 先行タスク [タスクを選択 ▼]            │
│ ステータス [未着手 ▼]                  │
│ 備考      [________________________]   │
│           [________________________]   │
│                                        │
│ [削除]        [キャンセル]  [保存]     │
└────────────────────────────────────────┘
```

※ タイトルは新規作成時「タスクを追加」、編集時「タスクを編集」。
※ 削除ボタンは編集モードのみ表示。
※ 開始日・終了日・日付再計算の2ボタンは、子タスクを持つ親タスクの場合は非表示（代わりに自動計算の案内文を表示）。

## 要素

| 項目 | 入力形式 | 備考 |
|------|----------|------|
| タスク名 | テキスト入力 | 必須 |
| 親タスク | ドロップダウン | プロジェクト内タスクから選択（自分自身・子孫は除外）。空欄 = ルートタスク |
| 担当者 | ドロップダウン | プロジェクト内の担当者一覧から選択 |
| 工数 | 数値入力 | 人日単位 |
| 開始日 | 日付ピッカー | 変更時に終了日を自動再計算（工数ベース） |
| 終了日 | 日付ピッカー | 手動変更可。工数との一致は不要 |
| 終了日を計算ボタン | ボタン（セカンダリ） | 開始日＋予定工数（稼働日カウント）から終了日を再計算して入力。開始日・予定工数が未入力の場合は非活性。後続タスクへの伝播は行わない |
| 先行タスクから開始日を設定ボタン | ボタン（セカンダリ） | 先行タスクの終了日の翌稼働日を開始日に入力（終了日は変更しない）。先行タスク未選択、または先行タスクの終了日が未設定の場合は非活性。後続タスクへの伝播は行わない |
| 先行タスク | ドロップダウン | プロジェクト内タスクから選択（自分自身・子孫は除外）。空欄も可 |
| ステータス | ドロップダウン | 未着手 / 進行中 / 完了 / 保留 |
| 進捗率 | 数値入力 | 0〜100 |
| 備考 | テキストエリア | 任意 |
| 削除ボタン | ボタン（危険色） | 編集モードのみ表示。確認ダイアログ（[common-rules.md](common-rules.md) 参照）後に削除 |
