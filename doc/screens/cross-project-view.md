# 横断ビュー

[ガントチャート](gantt-chart.md)と同じ「タスク一覧＋ガントチャート」の分割ペイン構成で、複数プロジェクトのタスクを1つの時間軸に横断表示する。編集操作は一切持たない読み取り専用画面。

## レイアウト

```
┌──────────────────────────────────────────────────────────────────────┐
│ [←戻る]  横断ビュー                                  [日 | 週 | 月]   │  ← ヘッダー
├──────────────────────────────────────────────────────────────────────┤
│ 表示するプロジェクト: ☑A ☑B ☐C          担当者 [すべて ▾]          │  ← プロジェクト選択・担当者フィルター
├────────────────────────────────┬─────────────────────────────────────┤
│ タスク名    担当 工数 開始  終了 ス 進 │ 6/1  6/2  6/3  6/4  6/5  6/6 ...  │
├────────────────────────────────┼─────────────────────────────────────┤
│ プロジェクトA                   │                                     │  ← プロジェクトグループ見出し
│ ▼ フェーズ1      - 10  6/1  6/14 未  0% │ ████████████████████            │
│   ▶ タスクA    山田  5  6/1  6/7  進 60% │ ██████████                      │
│ プロジェクトB                   │                                     │
│ ▶ フェーズ1      -  6  6/8  6/20 未  0% │           ████████████          │
└────────────────────────────────┴─────────────────────────────────────┘
```

## 要素

| 要素 | 説明 |
|------|------|
| 戻るボタン | [プロジェクト一覧](project-list.md) へ戻る |
| プロジェクト選択 | 全プロジェクトをチェックボックスで表示。選択状態は変更のたびに保存され、次回この画面を開いたときに復元される |
| 担当者フィルター | 選択中プロジェクトに登録された担当者名（重複除去）をドロップダウンで選択。一致するタスクとその祖先タスクのみ表示する。「すべて」で絞り込み解除 |
| スケールスイッチャー | 日 / 週 / 月 を切り替えるボタン（[ガントチャート](gantt-chart.md)と同じ） |
| プロジェクトグループ見出し | 選択中のプロジェクトごとに、プロジェクト名の見出し行をタスク一覧・ガントチャートの両ペインに表示してグループを区切る |
| タスクツリー | [ガントチャート](gantt-chart.md)と同じ列構成（タスク名・担当者・工数・開始日・終了日・ステータス・進捗）で階層表示 |
| ガントバー | タスクの期間をタイムライン上にバーで表示（ドラッグ操作・右クリックメニューなし） |

## 画面を開いたときのタイムライン位置

画面を開いた直後、ガントチャート（右ペイン）は今日の列が水平方向の中央に来る位置まで自動的にスクロールする。

## ガントチャートとの違い（編集機能を持たない）

* タスク行クリックによる編集モーダル、右クリックメニュー、タスクの追加・削除、ドラッグ＆ドロップによる並び替えは提供しない
* 先行・後続タスクの矢印表示は行わない（後述のとおりプロジェクトをまたぐ依存は無視するため）
* 同一担当者の稼働日重複警告・見積工数超過警告は表示しない

## 表示範囲

* 親子関係・先行後続関係は**プロジェクト単位で閉じて扱う**。プロジェクトをまたぐ `parent_id` / `predecessor_id` は表示上考慮しない（ツリー構築はプロジェクト内のタスクのみを対象とする）
* 親タスクの開始日・終了日は[ガントチャート](gantt-chart.md)と同じく子タスクから動的算出する。算出方法は[tasks](../tables/tasks.md)を参照
* タイムライン（時間軸）は選択中の全プロジェクトで共有する1本軸。表示開始日は選択中プロジェクトの開始日の最小値、表示終了日は選択中タスクの終了日の最大値+30日

## 選択状態の保存・復元

前回選択したプロジェクトIDをアプリ内に保存し、次回この画面を開いたときに復元する。保存されたプロジェクトが削除済みの場合は選択から除外される。初回起動時（保存がない場合）は未選択の状態で開き、プロジェクトを選択するよう促すメッセージを表示する。

## 空データ時の表示

* プロジェクトが1件も登録されていない場合、「プロジェクトが登録されていません」と表示する
* プロジェクトを1件も選択していない場合、「表示するプロジェクトを選択してください」と表示する
* 選択したプロジェクトにタスクが1件も登録されていない場合、そのプロジェクトグループ内に「タスクが登録されていません」と表示する
* 担当者フィルターの結果、該当するタスクが1件もないプロジェクトグループには「該当するタスクがありません」と表示する

## 担当者フィルターと担当者の同一性

担当者は[プロジェクト単位で登録・管理](../requirements/assignee-management.md)されアプリ全体では共有しないため、担当者フィルターは担当者名の文字列一致で絞り込む（プロジェクトをまたいで同姓同名の担当者が存在する場合は同一人物として扱われる）。
