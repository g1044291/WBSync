# プロジェクト一覧

## レイアウト

```
┌─────────────────────────────────────────────┐
│  WBSync                                    [☰] │  ← ヘッダー
├─────────────────────────────────────────────┤
│                                               │
│  ┌───────────────────────────────────────┐   │
│  │ プロジェクトA                          │   │
│  ├───────────────────────────────────────┤   │
│  │ プロジェクトB                          │   │
│  ├───────────────────────────────────────┤   │
│  │ プロジェクトC                          │   │
│  └───────────────────────────────────────┘   │
│                                               │
├─────────────────────────────────────────────┤
│                       [新規登録] [開発メニュー] │  ← フッター
└─────────────────────────────────────────────┘
```

ハンバーガーメニュー（☰）を開くと以下の項目が縦に並ぶ：

```
┌──────────────┐
│ 横断ビュー    │
│ 休日設定      │
│ 担当者設定    │
└──────────────┘
```

## 要素

| 要素 | 説明 |
|------|------|
| プロジェクト一覧 | プロジェクト名のみ表示。クリックで [ガントチャート](gantt-chart.md) へ遷移 |
| ハンバーガーメニュー（☰） | ヘッダー右端。クリックでメニューを開閉。メニュー外クリックで閉じる |
| メニュー：横断ビュー | クリックで [横断ビュー](cross-project-view.md) へ遷移 |
| メニュー：休日設定 | クリックで [休日設定モーダル](holiday-settings-modal.md) を開く |
| メニュー：担当者設定 | クリックで担当者設定モーダルを開く |
| 新規登録ボタン | フッター右寄せ。開発メニューボタンの左隣に配置。クリックで [プロジェクト作成モーダル](project-create-modal.md) を開く。常時表示 |
| 開発メニューボタン | フッター右端。デバッグビルド時のみ表示。クリックで開発メニュー画面へ遷移 |
