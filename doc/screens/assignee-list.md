# 担当者一覧

## レイアウト

```
┌────────────────────────────────────────┐
│ [←戻る]  担当者設定                     │
├────────────────────────────────────────┤
│                               [+ 追加]  │
│ ┌──────────────────────────────────┐  │
│ │ 山田 太郎                    [›]  │  │
│ │ 鈴木 花子                    [›]  │  │
│ │ 佐藤 一郎                    [›]  │  │
│ └──────────────────────────────────┘  │
└────────────────────────────────────────┘
```

## 要素

| 要素 | 説明 |
|------|------|
| 戻るボタン | [ガントチャート](gantt-chart.md) へ戻る |
| 担当者リスト | 登録済みの担当者を一覧表示。クリックで [担当者詳細](assignee-detail.md) へ遷移 |
| 追加ボタン | 担当者名入力欄を表示して新規追加（インライン or モーダル） |
