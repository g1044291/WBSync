# 共通ルール

## ステータスの表示

| ステータス | バッジカラー |
|------------|-------------|
| 未着手 | グレー |
| 進行中 | ブルー |
| 完了 | グリーン |
| 保留 | オレンジ |

## モーダルの共通動作

* 背景クリック or [×] ボタンで閉じる（未保存の変更がある場合は確認ダイアログを表示）
* [キャンセル] ボタンで変更を破棄して閉じる
* [保存] / [作成] ボタンでバリデーション後に保存

## 削除確認ダイアログ

タスク削除時は以下のダイアログを表示：

```
┌────────────────────────────────────┐
│ タスクを削除しますか？              │
│                                    │
│ 「タスクA」およびその配下のタスクを │
│ すべて削除します。この操作は元に    │
│ 戻せません。                        │
│                                    │
│              [キャンセル]  [削除]  │
└────────────────────────────────────┘
```
