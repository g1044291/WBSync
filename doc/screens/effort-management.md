## 要素

| 要素 | 説明 |
|------|------|
| 戻るボタン | [ガントチャート](gantt-chart.md) へ戻る |
| 稼働カレンダーボタン | [担当者別稼働時間カレンダー](assignee-workload-calendar.md) へ遷移 |
| 担当者フィルター | プロジェクト内の担当者で絞り込み。「すべて」が既定 |
| 遅れフィルター | 「すべて / 遅れあり / 遅れなし」。前倒し/遅れ工数（実績 − 予定工数、[../requirements/effort-management.md](../requirements/effort-management.md)参照）がプラス＝実績が予定工数を超過しているタスクを「遅れあり」とする（判定条件適用後の値で判定） |
| 並び替え | 「WBS順（既定） / 担当者順 / 遅れ順」。ツリー構造は維持したまま各階層内の兄弟ノードを並び替える（詳細は後述） |
| 折りたたみアイコン | ▼/▶ で子タスクの表示/非表示を切り替え（[ガントチャート](gantt-chart.md)と同様） |
| 展開アイコン | 行の左端。クリックで当該タスクの実績ログ入力パネルを展開/折りたたみ。子タスクを持つ行（親タスク）には表示しない（実績記録はリーフタスクのみ） |
| タスク名 | 階層に応じてインデント表示。クリックで[タスク編集モーダル](task-edit-modal.md)を開く（[ガントチャート](gantt-chart.md)と同様の導線） |

## タスクリスト列

| 列名 | 編集 | 備考 |
|------|------|------|
| タスク名 | 不可（クリックで編集モーダル） | 階層に応じてインデント |
| 担当者 | 不可 | このタスクの担当者。親タスクは自身に担当者が設定されていればその担当者名、未設定なら「-」 |
| 開始日 | 不可（参照のみ） | 変更は[タスク編集モーダル](task-edit-modal.md)で行う。親タスクは子から動的計算 |
| 終了日 | 不可（参照のみ） | 同上 |
| 見積工数 | 不可 | 人日。親タスクは自身に値があればその値、未設定なら子孫タスクの合計を動的表示 |
| 予定工数 | 不可 | 人日。親タスクは自身に値があればその値、未設定なら子孫タスクの合計を動的表示 |
| 実績（人日） | 不可（展開パネルから記録） | `work_logs.minutes` 合計 ÷ 480。親タスクは子孫タスクの合計を動的表示 |
| 残工数 | 不可 | 表示する予定工数 − 実績。マイナスの場合は赤字表示 |
| 前倒し/遅れ | 不可 | 実績 − 予定工数（人日）。プラス＝遅れ（実績が予定工数を超過、赤字＋⚠アイコン）、マイナス＝前倒し（ステータス「完了」時のみ算出）、それ以外は 0＝通常表示 |

※ 見積工数・予定工数・担当者・ステータス・進捗率などタスク本体の編集は[タスク編集モーダル](task-edit-modal.md)で行う。

※ 見積工数・予定工数・実績（人日）・残工数・前倒し/遅れにはいずれも単位「人日」を付与して表示する（例：`5.0人日`、遅れは `+1.5人日`、前倒しは `-1.5人日`、該当なしは `0人日`）。

## 実績ログ入力パネル（行展開）

* リーフタスク（子タスクを持たないタスク）の行のみ展開可能
* 展開すると、当該タスクに記録済みの実績ログを日付昇順で一覧表示する

| 列 | 内容 |
|----|------|
| 日付 | 作業日 |
| 担当者 | 記録時点の担当者。プロジェクト内の担当者から選択必須（実績は必ず誰かの作業のため未選択を許容しない） |
| 作業時間 | 分単位で入力。表示は分に加えて時間換算を参考値として併記する（例：`480分（8.0h）`） |
| コメント | 備忘用の任意メモ（文字数制限なし）。未入力の場合は空欄表示 |
| 編集/削除 | 行インライン編集、削除ボタン（確認ダイアログなし、即削除） |

* 一覧の下に追加フォーム（日付ピッカー・担当者ドロップダウン（既定＝タスクの現在の担当者）・分入力・コメント入力（任意）・追加ボタン）を表示する
* 分入力欄でEnterキーを押すと「＋ 追加」ボタンと同じ処理を実行する
* 追加フォーム・編集フォームとも担当者未選択で追加/保存しようとした場合はバリデーションエラーを表示する
* 追加・編集・削除後、当該タスクおよび祖先タスクの実績（人日）・残工数・前倒し/遅れを再計算して即時反映する

## フィルターの挙動

* 担当者フィルター・遅れフィルターに一致しないリーフタスクは非表示にする
* 一致するリーフタスクを子孫に持つ親タスクは表示を維持する（ルートまでのパスを保つ）。一致する子孫を持たない親タスクは非表示にする

## 並び替えの挙動

* 各階層の兄弟ノード同士を指定キーで並び替える（親子関係・インデントは変わらない）
* 担当者順：担当者名の五十音順（担当者未設定は末尾）
* 遅れ順：前倒し/遅れ工数（判定条件適用後）の降順（算出不可＝「-」は末尾）
* WBS順（既定）：[tasks.md](../tables/tasks.md)の `sort_order` 順（[ガントチャート](gantt-chart.md)と同じ表示順）
* 並び替えは表示上のみで、`sort_order` への保存は行わない
