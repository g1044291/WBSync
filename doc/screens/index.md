# UI設計

## 技術スタック

| 項目 | 採用技術 |
|------|----------|
| フレームワーク | .NET MAUI Blazor Hybrid (.NET 10) |
| UI コンポーネント | Razor コンポーネント（C#）+ Scoped CSS |
| D&D 並び替え | SortableJS（JS Interop 経由） |
| テーマ | ライトモードのみ |

## 画面一覧

| 画面名 | 概要 |
|--------|------|
| [プロジェクト一覧](project-list.md) | アプリ起動時の初期画面。プロジェクトを選択してWBSへ遷移 |
| [横断ビュー](cross-project-view.md) | 複数プロジェクトのタスクを1画面に横断表示する読み取り専用画面 |
| [ガントチャート](gantt-chart.md) | プロジェクトのWBSをタスクツリー＋ガントチャートで表示・編集 |
| [工数管理](effort-management.md) | 見積・予定・実績工数をツリー表示し、実績ログ・残工数・スケジュール遅延を管理 |
| [担当者別稼働時間カレンダー](assignee-workload-calendar.md) | 担当者×日付のマトリクス形式で日々の実績を一覧し、入力漏れを把握 |
| [ダッシュボード](dashboard.md) | 担当者別に工数の予定・実績・遅れを集計して一覧表示 |
| [タスク編集モーダル](task-edit-modal.md) | タスクの新規作成・編集を行うポップアップ |
| [休日設定モーダル](holiday-settings-modal.md) | アプリ全体の休日（祝日等）を登録・管理。プロジェクト一覧からモーダルで開く |
| [担当者一覧](assignee-list.md) | プロジェクトに登録された担当者の一覧 |
| [担当者詳細](assignee-detail.md) | 担当者名と個人休日を設定 |
| [プロジェクト作成モーダル](project-create-modal.md) | プロジェクトの新規作成を行うポップアップ |

## 画面遷移

```
[起動]
  └─► プロジェクト一覧
        ├─ プロジェクトをクリック ──────────────► ガントチャート
        │                                              ├─ タスク行クリック ──► タスク編集モーダル（編集）
        │                                              ├─ 右クリックメニュー「追加」─► タスク編集モーダル（新規）
        │                                              ├─ 担当者設定ボタン ──► 担当者一覧
        │                                              │                          └─ 担当者クリック ─► 担当者詳細
        │                                              ├─ 工数管理ボタン ──► 工数管理
        │                                              │                          └─ タスク名クリック ─► タスク編集モーダル（編集）
        │                                              ├─ 稼働カレンダーボタン ─► 担当者別稼働時間カレンダー
        │                                              ├─ ダッシュボードボタン ─► ダッシュボード
        │                                              └─ 戻るボタン ────────► プロジェクト一覧
        ├─ 横断ビューボタン ──────────────────► 横断ビュー
        │                                              └─ 戻るボタン ────────► プロジェクト一覧
        ├─ 新規登録ボタン ────────────────────► プロジェクト作成モーダル（モーダル）
        └─ 休日設定ボタン ────────────────────► 休日設定モーダル（モーダル）
```
