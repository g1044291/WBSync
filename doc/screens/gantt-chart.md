# ガントチャート

## レイアウト

```
┌──────────────────────────────────────────────────────────────────────┐
│ [←戻る]  プロジェクトA   [担当者設定] [工数管理] [稼働カレンダー]   [日 | 週 | 月] │  ← ヘッダー
├────────────────────────────────┬─────────────────────────────────────┤
│ タスク名    担当 工数 開始  終了 ス 進 │ 6/1  6/2  6/3  6/4  6/5  6/6 ...  │
│            当者      日   日 タ 捗 │                                     │
├────────────────────────────────┼─────────────────────────────────────┤
│ ▼ フェーズ1      - 10  6/1  6/14 未  0% │ ████████████████████            │
│   ▶ タスクA    山田  5  6/1  6/7  進 60% │ ██████████                      │
│   ▶ タスクB    鈴木  3  6/8  6/11 未  0% │          ██████                 │
│ ▼ フェーズ2      -  8  6/12 6/21 未  0% │                   ████████████  │
│   ▶ タスクC    山田  4  6/12 6/17 未  0% │                   ████████      │
├────────────────────────────────┼─────────────────────────────────────┤
│ [+ タスクを追加]                │                                     │
└────────────────────────────────┴─────────────────────────────────────┘
```

## 要素

| 要素 | 説明 |
|------|------|
| 戻るボタン | [プロジェクト一覧](project-list.md) へ戻る |
| プロジェクト名 | 現在のプロジェクト名を表示 |
| 担当者設定ボタン | [担当者一覧](assignee-list.md) へ遷移 |
| 工数管理ボタン | [工数管理](effort-management.md) へ遷移 |
| 稼働カレンダーボタン | [担当者別稼働時間カレンダー](assignee-workload-calendar.md) へ遷移 |
| スケールスイッチャー | 日 / 週 / 月 を切り替えるタブ or ボタン |
| タスク行 | クリックで [タスク編集モーダル](task-edit-modal.md) を開く |
| 階層展開アイコン | ▼/▶ で子タスクの表示/非表示を切り替え |
| 右クリックメニュー | 後述 |
| タスクを追加ボタン | ルートレベルのタスクを追加。クリックで [タスク編集モーダル](task-edit-modal.md)（新規）を開く |
| ガントバー | タスクの期間をバーで表示（ドラッグ操作なし） |

## タスクリスト列

| 列名 | 幅 | 備考 |
|------|----|------|
| タスク名 | 広め | 階層に応じてインデント。折りたたみアイコン付き |
| 担当者 | 固定 | 親タスクは「-」表示 |
| 工数 | 固定 | 単位：人日。親タスクは「-」表示 |
| 開始日 | 固定 | |
| 終了日 | 固定 | |
| ステータス | 固定 | バッジ or ラベル表示（色は [common-rules.md](common-rules.md) 参照） |
| 進捗率 | 固定 | 数値（%）表示 |

## 右クリックメニュー

```
┌──────────────────────────┐
│ 子タスクを追加            │
│ 同階層にタスクを追加      │
│ ──────────────────────── │
│ タスクを削除              │
└──────────────────────────┘
```

| 項目 | 動作 |
|------|------|
| 子タスクを追加 | [タスク編集モーダル](task-edit-modal.md)（新規）を開く。作成したタスクは右クリックしたタスクの最後の子として追加 |
| 同階層にタスクを追加 | [タスク編集モーダル](task-edit-modal.md)（新規）を開く。作成したタスクは同じ親の最後の子として追加 |
| タスクを削除 | 確認ダイアログ（[common-rules.md](common-rules.md) 参照）を表示後、タスクとその配下を削除。依存参照は削除 |

## タスクの並び替え

* 同一階層内でドラッグ＆ドロップによる順序変更が可能
* 異なる階層への移動は不可

## ガントチャートのスケール

| スケール | 列単位 | 表示例 |
|----------|--------|--------|
| 日 | 1列 = 1日 | 6/1, 6/2, 6/3 … |
| 週 | 1列 = 1週間 | 6/1〜6/7, 6/8〜6/14 … |
| 月 | 1列 = 1ヶ月 | 6月, 7月, 8月 … |

## 依存関係の警告表示

* 同一担当者の別タスクと稼働日が1日以上重複しているタスクの行を視覚的に警告表示（警告アイコンなど）

## 見積工数超過の警告表示

* 親タスクの行で、直接の子タスクの見積工数（人日）の合計が親タスク自身の見積工数を上回る場合、タスク名の横に警告アイコン（⚠）を表示する
* 親タスクの見積工数が未設定の場合は警告を表示しない
* 警告アイコンにマウスを乗せると、子タスク合計・親タスクの見積工数・超過量の具体的な数値をツールチップで表示する

## 画面を開いたときのタイムライン位置

画面を開いた直後、ガントチャート（右ペイン）は今日の列が水平方向の中央に来る位置まで自動的にスクロールする（[横断ビュー](cross-project-view.md)と同様）。スケール（日/週/月）切り替え時の再スクロールは行わない。

## 先行・後続タスクの矢印表示

* デフォルトはOFF。ヘッダーの「矢印」ボタンでON/OFFを切り替える
* 先行タスクの終了位置から後続タスクの開始位置へ矢印線を描画する（LeaderLine使用）
* 先行・後続タスクの両方が現在ガントチャート上に描画されている場合のみ矢印を表示する。折りたたみで一方が非表示になった場合は矢印も非表示にする（親タスクへの付け替えは行わない）
* タスクの追加・編集・削除、並び替え、スケール切り替え、折りたたみ操作の際に矢印を再描画する
* パネルのスクロールに追従して矢印の位置を更新する
