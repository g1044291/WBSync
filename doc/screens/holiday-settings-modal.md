# 休日設定モーダル

[プロジェクト一覧](project-list.md) の「休日設定」ボタンからモーダルとして開く。ページ遷移は発生しない。

## レイアウト

```
┌────────────────────────────────────────┐
│ 休日設定                            [×] │
├────────────────────────────────────────┤
│ ※ 土曜・日曜は固定休日です              │
│                                        │
│ 祝日・特別休日   [CSVインポート][＋ 追加]│
│ ┌──────────────────────────────────┐  │
│ │ 2025/01/01  元日          [削除]  │  │
│ │ 2025/01/13  成人の日       [削除]  │  │
│ │ 2025/02/11  建国記念の日   [削除]  │  │
│ └──────────────────────────────────┘  │
└────────────────────────────────────────┘
```

追加ボタンを押すと同モーダル内にインラインフォームを表示：

```
│ ┌────────────────────────────────────┐ │
│ │ [日付ピッカー] [休日名入力________] │ │
│ │               [取消]  [保存]       │ │
│ └────────────────────────────────────┘ │
```

## 要素

| 要素 | 説明 |
|------|------|
| × ボタン / 背景クリック | モーダルを閉じて [プロジェクト一覧](project-list.md) に戻る |
| 固定休日の注記 | 土日は自動的に休日であることを表示 |
| 休日リスト | 登録済みの休日を日付・名称付きで一覧表示 |
| CSVインポートボタン | ファイル選択ダイアログを開き、選択したCSVファイル（1列目に `yyyy/MM/dd` または `yyyy-MM-dd` 形式の日付）から休日を一括登録。既存データおよびCSV内の重複日付はスキップし、結果（登録件数・スキップ件数）をメッセージ表示 |
| ＋ 追加ボタン | モーダル内にインラインフォームを展開 |
| 削除ボタン | 対象の休日を削除 |
