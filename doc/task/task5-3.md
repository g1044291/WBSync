# 5-3 タスクツリー表示

## 作業詳細
- フラットなタスク配列からツリー構造（`parent_id` を基に）へ変換するロジック
- 階層レベルに応じたインデント表示
- 折りたたみアイコン（▼/▶）と展開・折りたたみ動作
- 各列の値を表示（親タスクは担当者・工数を「-」表示）
- ステータスをバッジで色分け表示
- 依存関係違反タスクに警告アイコンを表示（7-5と連携）

## 完了条件
- タスクが階層構造で正しく表示される
- 折りたたみ・展開が動作する
- 親タスクの開始日・終了日が子タスクから動的に計算されて表示される（7-6と連携）
- タスク行クリックでタスク編集モーダル（S03）が開く

## 残作業
- 依存関係違反タスクに警告アイコンを表示（7-5と連携）
