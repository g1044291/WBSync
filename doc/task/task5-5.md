# 5-5 右クリックメニュー

## 作業詳細
- タスク行右クリック時のコンテキストメニュー表示
- 「子タスクを追加」：S03を新規モードで開く（`parent_id` を右クリックしたタスクのIDにセット）
- 「同階層にタスクを追加」：S03を新規モードで開く（同じ `parent_id` をセット）
- 「タスクを削除」：確認ダイアログを表示して削除処理を実行（6-4と連携）
- メニュー外クリックでメニューを閉じる

## 完了条件
- 右クリックでコンテキストメニューが表示される
- 「子タスクを追加」で作成したタスクが右クリックしたタスクの子として追加される
- 「同階層にタスクを追加」で作成したタスクが同階層の末尾に追加される
- 「タスクを削除」で確認ダイアログが表示され、削除が実行される
