# 7-4 後続タスクへの再計算伝播

## 作業詳細
- タスクの `end_date` 変更時に `predecessor_id` が変更タスクIDのタスクを検索
- 該当タスクの `start_date` を「前タスクの `end_date` の翌稼働日」に更新
- `end_date` を新 `start_date` + `work_days`（7-2）で再計算
- 上記を再帰的に繰り返して連鎖伝播させる
- 変更後の値をDBに保存

## 完了条件
- タスクの終了日が変わると後続タスクの開始日・終了日が連鎖的に更新される
- 手動で開始日を変更済みのタスクも上書きされる
- 孫タスク以降にも正しく伝播される
