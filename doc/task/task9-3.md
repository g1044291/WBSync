# 9-3 エラーハンドリング

## 作業詳細
- EF Core 操作（SaveChanges）失敗時の例外キャッチとユーザーへの通知
- UNIQUE制約違反（重複登録）時の分かりやすいエラーメッセージ表示
- エラー通知UIの実装（トースト通知 or エラーモーダル）
- Blazor の `ErrorBoundary` コンポーネントを活用した予期しない例外のハンドリング

## 完了条件
- EF Core操作エラーが発生した際にユーザーに通知される
- 重複登録時に「同じ日付はすでに登録されています」等の具体的なメッセージが表示される
- エラーが発生してもアプリがクラッシュせず操作を継続できる
