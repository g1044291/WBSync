# 6-1 タスク編集モーダル（S03）UI

## 作業詳細
- 以下フィールドの入力フォームを実装
  - タスク名（テキスト入力・必須）
  - 担当者（ドロップダウン：プロジェクト内の担当者一覧）
  - 工数（数値入力：人日）
  - 開始日（日付ピッカー）
  - 終了日（日付ピッカー）
  - 依存タスク（ドロップダウン：自分自身・子孫を除くプロジェクト内タスク）
  - ステータス（ドロップダウン：未着手 / 進行中 / 完了 / 保留）
  - 進捗率（数値入力：0〜100）
  - 備考（テキストエリア）
- 新規作成・編集の判別（タイトルと初期値の切り替え）
- キャンセルボタンで変更なしに閉じる

## 完了条件
- 全フィールドが表示・入力できる
- 担当者・依存タスクのドロップダウンにプロジェクト内の選択肢が表示される
- 編集モード時は既存値が初期値として設定される
- 未保存変更がある状態でキャンセル時に確認ダイアログが表示される
