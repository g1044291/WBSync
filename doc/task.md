## 大タスク7：スケジュール計算エンジン

| # | 中タスク | 概要 |
|---|----------|------|
| 7-1 | 稼働日判定ロジック | 土日・全体休日・担当者個人休日を考慮した稼働日チェック関数 |
| 7-2 | 終了日自動計算 | 開始日 + 工数（稼働日カウント）で終了日を算出する関数 |
| 7-3 | FS依存による開始日設定 | 依存タスク設定時に前タスクの終了日翌稼働日を開始日に自動セット |
| 7-4 | 後続タスクへの再計算伝播 | タスク変更時に後続タスクを再帰的に再計算するロジック |
| 7-5 | 依存関係違反の警告検知 | 開始日が前タスク終了日以前の場合に警告フラグを立てる処理 |
| 7-6 | 親タスク日付の動的計算 | 子タスクの日付から親タスクの開始日・終了日をリアルタイムに導出 |
